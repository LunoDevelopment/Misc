💡How to use

In the directory provided, there should be an executable file, named "Luno Bootstrapper". This is a piece of software that will automatically download, install, repair, and update Luno. Running it should open up a console window that will download the main application.

Once it is finished, it should close and open up an executabile file, named "Luno". This is the main application. 

You will need to acquire a key in order to enter the main page. The key is relatively easy to obtain, and takes about a minute, and lasts for a while. You can purchase premium keys via our website.

Once entering a key, it will save that key onto your system for next time, and bring you to the main window automatically. 

Congrats! You're now officially using Luno.

📁Directories

"bin" - Contains directories that the application uses.
"scripts" - Contains quick-scripts that can be accessed by the script list / explorer.


"bin\Logs" - Contains log files, which will be created if an exception occurs, and contains information relating to the exception.
"bin\Monaco" - The Monaco code editor, by Microsoft, that we use.
"bin\Themes" - Contains theme files for the interface.
